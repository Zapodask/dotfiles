# Dotfiles

## Hyprland

### 🖥️ Keyboard Shortcuts

#### Applications and Window Management

| Shortcut     | Action                 |
| ------------ | ---------------------- |
| `Super + Q`  | Open terminal          |
| `Super + C`  | Close active window    |
| `Super + M`  | Exit Hyprland          |
| `Super + E`  | Open file manager      |
| `Super + G`  | Open browser           |
| `Super + R`  | Open menu              |
| `Super + D`  | Open database analyzer |
| `Super + A`  | Open requester         |
| `Super + W`  | Open music player      |
| `Super + F5` | Reload Waybar          |

#### Window Navigation

| Shortcut    | Action           |
| ----------- | ---------------- |
| `Super + H` | Move focus left  |
| `Super + L` | Move focus right |
| `Super + K` | Move focus up    |
| `Super + J` | Move focus down  |

#### Moving Windows

| Shortcut            | Action            |
| ------------------- | ----------------- |
| `Super + Shift + H` | Move window left  |
| `Super + Shift + L` | Move window right |
| `Super + Shift + K` | Move window up    |
| `Super + Shift + J` | Move window down  |

#### Workspaces

##### Navigate Workspaces

| Shortcut               | Action                      |
| ---------------------- | --------------------------- |
| `Super + [1-9, 0]`     | Go to specific workspace    |
| `Super + Mouse Scroll` | Navigate between workspaces |

##### Move Windows to Workspaces

| Shortcut                   | Action                            |
| -------------------------- | --------------------------------- |
| `Super + Shift + [1-9, 0]` | Move window to specific workspace |
| `Super + S`                | Toggle special workspace (magic)  |
| `Super + Shift + S`        | Move to special workspace         |

#### Window Layouts and Settings

| Shortcut              | Action               |
| --------------------- | -------------------- |
| `Super + V`           | Toggle floating mode |
| `Super + P`           | Pseudo mode          |
| `Super + Ç`           | Toggle split         |
| `Super + Left Click`  | Move window          |
| `Super + Right Click` | Resize window        |

#### Media and System Control

##### Volume and Brightness

| Shortcut                | Action                 |
| ----------------------- | ---------------------- |
| `XF86AudioLowerVolume`  | Decrease volume        |
| `XF86AudioRaiseVolume`  | Increase volume        |
| `XF86AudioMute`         | Mute/Unmute sound      |
| `XF86AudioMicMute`      | Mute/Unmute microphone |
| `XF86MonBrightnessDown` | Decrease brightness    |
| `XF86MonBrightnessUp`   | Increase brightness    |

##### Media Control

| Shortcut        | Action         |
| --------------- | -------------- |
| `XF86AudioPlay` | Play/Pause     |
| `XF86AudioNext` | Next track     |
| `XF86AudioPrev` | Previous track |

#### Tools

| Shortcut            | Action              |
| ------------------- | ------------------- |
| `PRINT`             | Screenshot (region) |
| `Super + Shift + Ç` | Lock screen         |
